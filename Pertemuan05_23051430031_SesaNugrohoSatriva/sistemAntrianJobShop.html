Simulasi Antrian Pekerjaan Mesin

Program ini mensimulasikan sistem antrian pada lingkungan job shop menggunakan array of object. Setiap job memiliki atribut idJob, namaProses, dan durasi (menit). 

let antrianMesin = [
    { idJob: "J01", namaProses: "Drilling", durasi: 30 }
];

Function prosesAntrian() digunakan untuk menampilkan setiap job dalam antrian menggunakan perulangan for. 

function prosesAntrian(antrianMesin) {
    for (let i = 0; i < antrianMesin.length; i++) {
        let job = antrianMesin[i];
        console.log(
            "Memproses Job " + job.idJob +
            " - " + job.namaProses +
            " selama " + job.durasi + " menit"
        );
    }
}

Setelah itu, program menambahkan job baru ke dalam array menggunakan method push(), kemudian function dipanggil kembali untuk menampilkan daftar terbaru.

Selain menampilkan data pada console, program juga menampilkan daftar antrian pada halaman web. Hal ini dilakukan dengan memanfaatkan manipulasi DOM menggunakan document.getElementById() dan membuat elemen <li> secara dinamis untuk setiap job yang ada di dalam array. 

function tampilkanAntrian(){
const list = document.getElementById("listAntrian");

antrianMesin.forEach(job => {
    const item = document.createElement("li");
    item.textContent =
    "Job " + job.idJob +
    " - " + job.namaProses +
    " (" + job.durasi + " menit)";
    list.appendChild(item);
});
}

Program juga menyediakan form untuk menambahkan job baru. Ketika tombol Tambah ditekan, function tambahJob() akan dijalankan. Function ini membaca nilai dari input idJob, namaProses, dan durasi menggunakan document.getElementById(). 

function tambahJob(){
    const idJob = document.getElementById("idJob");
    const namaProses = document.getElementById("namaProses");
    const durasi = document.getElementById("durasi");

    antrianMesin.push({
        idJob: idJob.value,
        namaProses: namaProses.value,
        durasi: durasi.value
    });
    console.log("--- Setelah Menambahkan Job dari Form ---");
    prosesAntrian(antrianMesin); // update console

    tampilkanAntrian();
    
    idJob.value = "";
    namaProses.value = "";
    durasi.value = "";
}

Data yang diperoleh dari input kemudian dimasukkan ke dalam array antrianMesin menggunakan method push(). Setelah data berhasil ditambahkan, function tampilkanAntrian() dipanggil kembali untuk memperbarui daftar antrian yang ditampilkan pada halaman. Terakhir, nilai pada input akan dikosongkan kembali agar pengguna dapat menambahkan job berikutnya dengan mudah.

Hasil simulasi dapat dilihat melalui Console Browser (F12 → Console) dan pada halaman.
